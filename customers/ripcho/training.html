Operator onboarding

Training center

A hands-on training sequence for Ripcho operators. Read the procedure, observe an experienced operator, then complete the task under supervision before working independently.

Training rule: Never use a live job as a practice area without a lead present. Keep the progress sheet with the job and record work as it is completed.

Phase 1: Learn the production controls

  1. Learn the physical flow: incoming job → image preparation → output → service items → packing → billing/shipping or studio delivery.
  2. Learn to use the job email, work order, current flyer, and progress sheet as the authoritative job record.
  3. Learn the three required stop points: totals that do not match, an unknown product/order mapping, and a print or image issue that may affect a full run.
  4. Learn first-piece inspection and how to report a defect with the job name, queue, affected product, and screenshot or photo when possible.

Phase 2: Underclass / Class Picture

Open UG / CP workflow

  • Observe an operator set up a work order, copy the incoming job folders, import a TNJ, and reconcile paper/online totals.
  • Practice retouch export, refresh, and green-check closeout under supervision.
  • Practice color correction, proof-card setup, and verifying proof-card/queue sort order.
  • Observe Noritsu, Dye Sub, labels, stickers, and directory output before independently releasing a queue.

Phase 3: Specialized workflows

Retakes

Train on isolating retake work and protecting the original Day 1 job.

Spring Portraits

Train on background application, Safety Cards, and Spring job closeout.

Sports / Memory Mates

Train on teams, graphics, specialty items, and studio pickup packing.

Composites

Train on CSV data, packing labels, order sequence, and Test ROES.

Phase 4: Demonstrate readiness

  1. Use the correct current progress sheet without prompting.
  2. Identify the current flyer and explain why an old flyer cannot be used as the product source of truth.
  3. Set and verify matching sort orders for output that must pack in sequence.
  4. Complete a first-piece check and correctly route a problem for escalation.
  5. Finish a supervised job through packing and closeout, including the required billing/IOS checks for that workflow.

Working vocabulary

TermMeaning in Ripcho production
Progress sheetThe job's live production checklist, count record, and closeout guide.
Proof / Safety CardJob output used to organize and verify production; its sequence must match the print queue when packing depends on order.
Service itemSupplemental output such as stickers, directories, magnets, Dye Sub products, labels, buttons, or specialized items.
First-piece checkInspect the first completed item before allowing a full production run to continue.
IOS checkVerification step confirming a successful IOS upload using a locator number.

Current production workflow

Spring portraits

Process Spring Portrait jobs from the incoming TNJ through proof cards, production output, shipping, and IOS verification.

Use the current job information. The job email, work order, and active Spring flyer control package setup, sort order, special instructions, and shipping details.

Download the Spring Portrait progress sheet

1. Preproduction

  1. Create the LabWorks work order using code RSP; record the work-order number on the progress sheet.
  2. Copy the job Images and Graphics folders to the Ripcho MySQL location and remove the #Images and #Graphics suffixes.
  3. Import the TNJ from the current Ripcho FTP job folder. For the expected missing-image notice, hold Shift and choose Ignore.
  4. Verify the job year/season is correct before moving forward.

2. Orders, backgrounds, and retouching

  1. Reprocess orders in Orders mode, then compare the imported paper and online totals to the work order.
  2. In Images mode, select all images and use Ctrl + Alt + K to set backgrounds for paper orders.
  3. Complete requested retouching and record the total by X1, X2, and X3 as applicable. Use the green check in Orders mode to clear completed retouch work.

3. Proof cards and print queues

Sort control: Apply the requested sort to both the print queue and Safety Card set. Check both sorts a second time before printing, and make sure Point n' Click is unchecked in Queue mode.
  1. Color correct images; if a crop looks incorrect, check crop before continuing. Record the corrected-image total.
  2. Create and print Safety Cards using the approved printer/queue. Record the quantity.
  3. Print magnets, Dye Sub, Dye Sub labels, digital downloads, and Noritsu work as required. Scroll the entire Noritsu queue and escalate anything that looks wrong.
  4. Export and print Queue Statistics, then staple it to the work order for billing.

4. Billing, packing, shipping, IOS

  1. Update the LabWorks work order using the recorded totals and Queue Statistics. Complete the printing and billing production-node/checkered-flag steps.
  2. Complete IOS upload, then verify it with an IOS check and locator number before closeout.
  3. Quality-check prints during packing. Watch for dust lines, white spots, or color problems; notify a printer immediately if a problem is found.
  4. Seal envelopes; put Dye Sub products in the envelope except mugs; group work by the requested class/sort. Check the job email for special instructions.
  5. For shipping, add newsprint, keep paperwork out of the box, scan the invoice, confirm the address in email and UPS software matches, print the label, and record the ship date.

Quick stop points

Paper or online totals do not match

Do not print. Recheck the work order, import settings, and Orders mode totals before releasing output.

Safety Cards and print queue have different sort orders

Correct the sort and verify it again. Packing depends on the two outputs remaining in the same sequence.

A crop or color correction looks wrong

Check crop first, then correct only the affected image. Ask for help before releasing a full queue if the issue is unclear.

Production workflow

Spring portraits

Use the Spring Portrait progress sheet and approved package flyer for the current season. Product selections and package codes can vary by school.

  1. Review the job, customer instructions, current flyer, and progress sheet.
  2. Verify subject data, images, proof requirements, and current package configuration.
  3. Complete retouching and required image preparation before proofs or production output.
  4. Release products to the correct print and service-item queues.
  5. Check completed products against the current package reference before packing.
Seasonal note: Always use the flyer and setup assigned to the current job. Do not assume an earlier season’s packages or proof process is still active.

UG / CP workflow

The working procedure for Ripcho Underclass / Class Picture jobs—from the incoming email through billing, packing, shipping, and IOS confirmation.

Keep the job together. Start with a current progress sheet, the job email, and its reorder-pricing attachment. Record the work-order number, offer, requested sort, paper/online order totals, image count, retouch totals, downloads, and service items as you go.

Download the detailed UG / CP progress sheet

1. Pre-production

  1. Create the Ripcho LabWorks work order using code RUG. Add and verify the school shipping address; use the current job email as the source of truth.
  2. Print the reorder-pricing attachment and keep it stapled behind the progress sheet and job email.
  3. Copy the job's Images and Graphics folders from the FTP location into the matching Ripcho MySQL folders. Remove the #Images and #Graphics suffixes after the copy completes.
  4. In NeoPack Details mode, import the TNJ. Verify the correct season, workspace, and account; preserve keys. When the expected missing-image message appears, hold Shift and choose Ignore.
  5. Reprocess orders. Record the offer/preview template, requested sort, folder structure, and paper/online totals. Compare database totals to the job email and stop for a mismatch.

2. Retouch and color correction

  1. In Orders mode, export requested retouch images and record the total. Use the requested level: X1 blemishes, X2 teeth whitening, X3 braces removal, or X4 full retouch.
  2. Return completed files to the job image folder, replacing the corresponding files. In Images mode, refresh the retouched images; then use the green check in Orders mode to mark retouch work complete.
  3. In Images mode, color correct primary poses. Start with density; make additional corrections only when needed. Record the number of corrected images for billing.
  4. For a Class Picture job, remove corrections from class pictures at the end of the set before releasing output.

3. Sort queue and proof cards

Use the sort requested on the work order. Folder / Subject is common, but use Grade / Room / Name when the requested sort and job folder structure require it. Apply the same sort to the print queue and proof cards.

  1. Create a new Item Sheet for proof cards. Select all subjects; for a CP job, unselect the Class Picture folder. Rename it Proof Sheet.
  2. Select the approved UG-MM Image Proof Card item. On the page settings screen, use the job sort, select Ignore unmatched subjects, and leave both ordered/not-ordered filters unchecked.
  3. Verify sort order before printing: the first and last subjects with orders on proof cards must match the first and last subjects with orders in the print queue.
  4. Print proof cards to Noritsu Hot Folder using the approved hot-folder properties and Noritsu34Pro_Supra_VC.icm profile. Record the count. Do not use internal thumbnail images for this proof-card output.

4. Print production queues

Before any queue output: make sure Point n' Click is not selected in Queue mode. Print each queue intentionally and mark it complete on the progress sheet.
QueueRequired action
MagnetsReview crops, print to the approved Noritsu Hot Folder, and attach a school-name magnet note to the job.
Dye SubUse Generic Bitmap with the sRGB profile and the approved Dye Sub bitmap path. Print the complete queue together, then route product to Dye Sub production.
Dye Sub labelsUse the approved Brother label queue with the sRGB profile. Place the printed label roll in the Dye Sub area.
Digital downloadsUse Output to Disk / Digital Upload with all selected and Ignore unmatched subjects. Count each release-plus-image pair as one download and record the total.
Noritsu packagesUse the same approved Noritsu Hot Folder and profile as proof cards. Keep printed stacks in sequence and watch for dust lines every time a stack is removed.

5. Service items

Read job-email instructions before starting any service item. Job-specific instructions override the defaults below.

Stickers

Use the current _STICKERS template, approved sort and Fiery CUME_Stickers preset. Inspect the first sheet before a full run.

Directories

Use the current _DIRECTORY template, preserve the requested output order, then build and print from the directory master job.

Other service items

Label every completed service-item package with school, item, quantity, and sort order; add chipboard behind each sticker set.

Class pictures

Print office, teacher, and faculty sets as required. Clear the Point n' Click queue between separate runs and use Queue Statistics for the actual counts.

6. Billing and closeout

  1. Export Order Statistics and tally retouch codes X1–X4. Record the results on the progress sheet.
  2. Export Queue Statistics with price codes, print it, and staple it behind the job paperwork. Confirm it is the correct job before billing.
  3. Open the LabWorks work order and use the RUG billing template if it is not already present. Enter proof cards, color-corrected image total, digital downloads, service items, and Queue Statistics quantities. Verify shipping address and reference before saving.
  4. Complete the prepared-order/checkered-flag steps after the bill has been reviewed.

7. Packing, shipping, and IOS

  1. Quality-check prints while packing for dust lines, white spots, and color problems. Stop and notify a printer if a defect is found.
  2. Confirm all service items are made. Seal envelopes; put Dye Sub in the envelope except mugs; group envelopes by the requested class/sort.
  3. For drop shipments, add newsprint, keep paperwork out of the box, scan the invoice barcode, and confirm the email and UPS addresses match before printing the label.
  4. Record the ship date, place the box for UPS pickup, and send the remaining paperwork to the assigned upload process.
  5. Complete IOS upload and verify it with an IOS check before marking the job complete.

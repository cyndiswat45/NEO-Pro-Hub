Sports / Memory Mates

Process Ripcho sports jobs from job setup through team graphics, personalized products, packing, studio delivery, and IOS verification.

Sports setup is school-specific. Verify the active season/workspace, current flyer, school templates, graphics, and team images before you reprocess orders or release output.

Download the Sports / Memory Mate progress sheet

1. Set up the job

  1. Create the LabWorks work order using code RMM and record the number on the progress sheet.
  2. Copy images and templates from FTP to the appropriate MySQL location. Remove the copied-folder suffixes after transfer.
  3. Copy the school-specific print templates from the shared Ripcho sports template library into the job template folder.
  4. Import the TNJ into SQL / NeoPack. Confirm the correct season and workspace, then verify the year, graphics, and team images before proceeding.
  5. Reprocess orders after the configuration is confirmed.

2. Prepare images

  1. Retouch requested images and record the total.
  2. In Images mode, select all images and use Ctrl + Alt + K to apply required backgrounds.
  3. Color correct and inspect crops. Record the count of completed images.
  4. Sort the queue using Folder / Subject where the job structure supports it.

3. Print queues and service items

Print-control rule: print each output intentionally and record it immediately. Verify the first finished product when a printer, stock, or product type changes.
OutputRequired check
Safety CardsPrint and record the quantity before the package queues are released.
Photographic queuesUse the designated 3101, 3203, 3412, or 3412SM queue for the job; retain the job's requested sequence.
Buttons and magnetsMake a job-name/date note for 3-inch buttons; record 4×5 magnets and keep specialty work identified.
Dye Sub, labels, LogoJETRelease to the appropriate output path and verify every requested personalized/service item is made.
Digital downloadsUse Output to Disk with Fulfill open. Count and record the total.
Team productsRecord T1 11×14, T2 8×10, T3 5×7, 16×20, and foam-core quantities as required.

4. Billing and tracking

  1. Print Queue Statistics and use the results to complete the LabWorks invoice.
  2. Complete the production-node/checkered-flag steps after printing and billing are verified.
  3. Write the job on the production whiteboard until it is complete.
  4. Complete IOS image upload and verify an IOS locator number before final closeout.

5. Pack for studio pickup or delivery

  1. Quality-check prints during packing for dust lines, white spots, and color problems. Notify a printer immediately if an issue appears.
  2. Check the job email for special notes. Confirm buttons, magnets, Dye Sub, LogoJET, and all other service items are made, labeled, and bagged.
  3. Do not place 3-inch buttons in envelopes. Keep them together in a bag labeled with the job name.
  4. Close envelopes; put Dye Sub products in the envelope except mugs. Remove the job from the production board once packing is complete.
  5. Put the finished job on the Ripcho shelf for pickup/delivery with the invoice. Return remaining paperwork to the printer.

Sports flyer variations

Use the job's flyer as the final authority. Aurora and Harmon use a sports-package variation; do not assume optional products from the standard sports flyer are offered on their jobs.

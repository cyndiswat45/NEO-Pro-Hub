Composites

Composites depend on clean import mapping and quantity control. Validate the data set before sending any output.

  1. Use the approved composite template and current job data.
  2. Map fields carefully—commonly first name, last name, grade, teacher, and quantity.
  3. Review unmatched or incomplete records before generating output.
  4. Validate the preview, selection, and copies/quantity column before printing.
  5. Send output to the approved production device and verify the first completed sample.
Quality check: Confirm names, class/teacher information, and quantity against the job source before a full run. Fix data issues before reprinting.

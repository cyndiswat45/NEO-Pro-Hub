Composites

Build, label, order, and release Ripcho composite jobs with correct student, office, staff, and book quantities.

Count before you order. The student set, office set, staff/faculty composites, book pages, and number of data lines can all bill differently. Record each total on the composite progress sheet before sending any order.

Download the Composite progress sheet

1. Set up job and source data

  1. Create a LabWorks work order for Ripcho Studio Photography and set the reference to the school composite job for the current season.
  2. Use RS0810G for 8×10 composites and record RSPACK as the number of lines of data.
  3. Copy the composite job from FTP into the current Ripcho Work location.
  4. Copy data from the job email into a new Excel sheet. Export it as a CSV (Comma Delimited) and save it under the Composite Labels work area using the school name.

2. Calculate and record quantities

QuantityHow to use it
Student compositesSum the student composite quantities to produce and bill.
Per-class compositesSum and record separately on the job email / progress sheet.
Office setRecord separately. Do not print an office set when a book is ordered.
Staff/faculty compositesRecord the total separately.
Composite bookUse RSUGCP and record page count and quantity according to the work order.

3. Import data and print labels

  1. Open the Composite Labels job in NeoPack. Enter the full school name and verify the year.
  2. Import the school CSV through File → Import Text File.
  3. In Details mode, enter office-set quantity. If a composite book is requested, enter BOOK instead of an office quantity. Enter staff/faculty quantity as required.
  4. Record the total number of lines in Details mode for RSPACK billing.
  5. In Item Sheets mode, select Packing Label. Use template PL_GR_T_R_Qty, sort Grade / Teacher / Name, and print labels. Wait for successful output before closing.
  6. Do not save over the TNJ. Close the labels job after printing.

4. Order, release, and bill

  1. Order composites in Test ROES. Keep the office set separate from the student set.
  2. Order the student set in the same sequence as the printed labels. Use the work order and recorded totals to ensure every composite receives the correct count.
  3. Update the LabWorks work order with the recorded quantities and save the invoice.
  4. Send the job through ROES Server. Keep the work order and printed labels together and place them in the designated Biggie-printer basket.
  5. Write the job name on the packing board. Ship only when Ripcho supplies a delivery address; otherwise, prepare the job for Ripcho delivery.

Stop and verify

CSV import has unmatched or incomplete records

Stop before labels or ROES orders. Confirm source data, school name, year, field mapping, and quantity values.

Office set and book request both appear

Do not assume both should print. The current process says not to print the office set when a book is ordered; confirm with the work order if unclear.

Printed labels do not match the student order sequence

Stop before placing a ROES order. Reprint or correct labels so the physical order matches the order sequence.
